### Задание 1.

```cpp
#include <iostream>

using namespace std;

int main()
{
    float af = 1000, bf = 0.0001;
    double ad = 1000, bd = 0.0001;

    //Вычисления для float с использованием промежуточных переменных
    float sumf = af + bf; // a + b
    float sqsumf = sumf * sumf; // (a + b)^2
    float sqaf = af * af; // a^2
    float sqbf = bf * bf; // b^2
    float twoabf = 2 * af * bf; // 2ab
    float resultf = ( sqsumf - (sqaf + twoabf) )/ sqbf;
    cout << "Float type result: " << resultf << endl;

    //Вычисления для double с использованием промежуточных переменных
    double sumd = ad + bd; // a + b
    double sqsumd = sumd * sumd; // (a + b)^2
    double sqad = ad * ad; // a^2
    double sqbd = bd * bd; // b^2
    double twoabd = 2 * ad * bd; // 2ab
    double resultd = ( sqsumd - (sqad + twoabd) )/ sqbd;
    cout << "Double type result: " << resultd << endl;
    
    return 0;
}
```
Исходные данные: a = 1000, b = 0.0001
- Результат  работы программы для данных типа float: 6.25e+06
- Результат работы программы для данных типа double: 1.00117

На самом деле данное выражение упрощается до единицы (b^2/b^2).

Типы float и double имеют разную точность: Float зфнимает 4 байта, double - 8 байт.

 Float не может одновременно хранить и большую целую часть, и очень маленькую мантиссу. При сложении младшие разряды "теряются", что приводит к погрешности округления. В итоге числитель не в точности равен b^2 и результат отклоняется от единицы. Погрешность float в данном случае составляет миллионы процентов, что делает его абсолютно непригодным для подобных вычислений.

 Double обладает достаточной точностью, чтобы сохранить все разряды, поэтому результат получается близок к 1, а погрешность 0.1% объясняется накоплением ошибок округления при многочисленных операциях.

### Задание 2.
```cpp
#include <iostream>
using namespace std;


int main()
{
    int m, n;
    cout << "Enter m: ";
    cin >> m;
    cout << "Enter n: ";
    cin >> n;

    int m1 = m, n1 = n;
    cout << "1) m-++n = " << m1 - ++n1 << " (n -> " << n1 << ")" << endl;

    int m2 = m, n2 = n;
    cout << "2) ++m>--n = " << (++m2 > --n2) << " (m -> " << m2 << ", n -> " << n2 << ")" << endl;

    int m3 = m, n3 = n;
    cout << "3) --n<++m = " << (--n3 < ++m3) << " (m -> " << m3 << ", n -> " << n3 << ")" << endl;

    return 0;
}
```
Начальные значения m и n вводятся с клавиатуры.
Пример работы программы (при m = 5, n = 10):
1) m-++n = -6 (n -> 11)
2) ++m>--n = 0 (m -> 6, n -> 9)
3) --n<++m = 0 (m -> 6, n -> 9)

Выражение 1: m - ++n


   Оператор ++n - это префиксный инкремент. Сначала значение n увеличивается на 1 (становится 11), и только потом выполняется вычитание: 5 - 11 = -6.

Выражение 2: ++m > --n

   Сначала срабатывают оба префиксных оператора: m увеличивается на 1 (становится 6), n уменьшается на 1 (становится 9). Затем выполняется сравнение: 6 > 9. Условие ложно, поэтому результат равен 0.

Выражение 3: --n < ++m

   Сначала n уменьшается на 1 (становится 9), m увеличивается на 1 (становится 6). Затем сравнение: 9 < 6. Условие ложно, результат равен 0.

Результатом логических выражений (>, <) в C++ является 1 (истина) или 0 (ложь). В наших примерах оба сравнения оказались ложными, поэтому выведены нули.

**Вывод:**

Префиксные операторы ++ и -- изменяют значение переменной до её использования в выражении. Понимание порядка вычислений критически важно, так как от него зависит конечный результат программы.
