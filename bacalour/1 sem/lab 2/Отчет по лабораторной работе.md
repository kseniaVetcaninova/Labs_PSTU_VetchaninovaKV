### Постановка задачи
Испольвуя оператор цикла, найти сумму ряда с точностью $\varepsilon = 10^{-4}$, общий член которого $a_n = \frac{1}{2^n} + \frac{1}{3^n}$. Результат напечатать снабдив соответствуюшим заголовком.

### Текст программы

```cpp
#include <iostream>
#include <clocale>
using namespace std;

int main()
{
    setlocale(LC_ALL,".65001");
    long double e = 1e-4, sum = 0, an, n = 1, p2 = 2, p3 = 3;
    do
    {
    an = (1 / p2) + (1/p3);
    sum += an;
    p2 *= 2;
    p3 *= 3;
    n++;
    } while (an >= e);

    cout<< "Сумма ряда с точностью e = 10^4: "<< sum <<endl;
    cout<< "Количество учтенных членов ряда: "<< n - 1 << endl;
    cout<< "Последний вычисленный член ряда: " << an << endl;

    return 0;

}
```
### Результат решения
- Сумма ряда с точностью e = 10^4: 1.49994
- Количество учтенных членов ряда: 14
- Последний вычисленный член ряда: 6.12442e-05
